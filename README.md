# Profiles
## init.ps1
This script allows me to setup the windows pc to run the `cmd` files globally just by using the file name without `.cmd`

## hello.cmd
test script to run.
```cmd
// run with default variable
hello 
// returns Hello, World!


// run with different Name
hello shawn
// returns Hello, shawn!

// run with switch variable
hello shawn -Loud
// return HELLO, SHAWN!

```
